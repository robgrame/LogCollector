# LogCollector Azure backend 1.13.7

## Changed

- Adds `UserCorrelationId:string` to `EndpointDataSprawlRemediator_CL` for the current
  pseudonymous per-user dashboard telemetry contract.
- Preserves the existing endpoint data-sprawl cycle, file-result, privacy and volume-control
  columns and their Azure Monitor types.
- Keeps the DCR stream, pass-through data flow, Frontend allowlist and Worker ingestion mapping
  generated from the same authoritative table definition.

## Deployment

Deploy only the infrastructure target to `LOGCOLLECTOR-RG`, then verify the table schema, DCR
stream and both Function App `Ingestion__StreamMap` settings before enabling dashboard queries.

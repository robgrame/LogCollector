# LogCollector 1.13.5

## Azure backend

- Adds the initial endpoint data-sprawl telemetry destination definition.
- This destination was renamed before deployment by Azure backend 1.13.6.
- Adds the table-to-stream mapping to both Frontend and Worker through the existing generated
  `Ingestion__StreamMap`.
- Supports the endpoint data-sprawl client cycle, file-result, privacy and volume-control fields.

No LogCollector Client module update is required. The endpoint data-sprawl client continues to
submit through `Send-LogCollectorData` and the existing `/api/submit` endpoint.

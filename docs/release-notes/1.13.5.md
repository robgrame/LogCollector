# LogCollector 1.13.5

## Azure backend

- Adds the authoritative `OneDriveFileOrganizer_CL` table definition.
- Adds the corresponding `Custom-OneDriveFileOrganizer_CL` DCR stream and data flow.
- Adds the table-to-stream mapping to both Frontend and Worker through the existing generated
  `Ingestion__StreamMap`.
- Supports the OneDrive File Organizer 0.4.0 cycle, file-result, privacy and volume-control fields.

No LogCollector Client module update is required. OneDrive File Organizer continues to submit
through `Send-LogCollectorData` and the existing `/api/submit` endpoint.

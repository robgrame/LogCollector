# LogCollector 1.15.2

- Preserve Custom Inventory 1.9.1 compatibility with LogCollector Core 1.11.1 and later.
- Avoid provisioning Endpoint Data Sprawl App Configuration, Key Vault, user-session table, and related RBAC when both user sessions and SQL persistence are disabled.
- Keep generic deployment parameters free of EDSR telemetry while preserving an explicit Log Analytics-only opt-in and compatibility with legacy parameter files that already declare the table.
- Skip user-session cleanup when the feature is not configured.
